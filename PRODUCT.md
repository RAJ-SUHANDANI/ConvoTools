# ConvoTools

Browser utilities for people preparing documents, images, data and media for their next task. Start with a file or find a named tool. No account is required. Files and output are processed in the browser; optional engines download runtime assets from third-party CDNs. Preferences and activity remain on the device.

The registry contains 42 tools across 10 categories. Four AI lab entries are explicitly coming soon. Do not describe them as usable, invent customer counts, testimonials, savings or format fidelity. PDF reconstruction and OCR require review. PDF compression rewrites structure rather than promising a smaller image payload. Media processing has a 180 MB input limit.

The landing page explains the whole toolkit through PDF, image, document, spreadsheet, presentation, media, archive and developer workflows. Sample interactions must do real work or be explicitly labelled previews. Conversion pages prioritize input, settings, progress and output. Workspace activity is local metadata, not cloud file storage.
